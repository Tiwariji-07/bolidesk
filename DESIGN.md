# BoliDesk Design System

## Visual Theme

Light, desk-ready operations software for a business owner checking collections in daylight or under shop lights. Restrained colour: warm sand work surfaces, inky navy navigation and type, with green reserved for cash-moving actions and healthy states.

## Color Palette

- Ink: `oklch(0.23 0.035 258)`
- Ink soft: `oklch(0.38 0.03 258)`
- Sand canvas: `oklch(0.965 0.018 82)`
- Sand surface: `oklch(0.992 0.008 82)`
- Line: `oklch(0.88 0.015 82)`
- Green: `oklch(0.53 0.13 151)`
- Green dark: `oklch(0.39 0.10 151)`
- Amber: `oklch(0.67 0.13 75)`
- Red: `oklch(0.56 0.18 26)`

## Typography

System sans stack. Compact 12–14px labels, 16px body, 20–28px page headings. Tabular figures for monetary data.

## Components

Soft 10px corners, thin warm borders, clear visible focus rings, quiet panels, pill status labels, and one consistent green primary button. Use skeleton rows for loading and instructional empty states.

## Layout

Left navigation at desktop, compact top navigation on mobile. Keep key actions in a visible header and use responsive detail lists rather than forcing wide tables on narrow screens.
